# Muhammad Afif Jovi — Portfolio

Static portfolio prepared for GitHub Pages. The featured Digital Operations Portal case study is anonymized: no company logo, company name, proprietary data, or identifying interface details are included.

## Publish with GitHub Pages

1. Upload every file and the `assets` folder to the root of your GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. GitHub will publish the site at `https://<username>.github.io/<repository>/`.

All paths are relative, so the site works from both a user/organization Pages repository and a project Pages repository.
